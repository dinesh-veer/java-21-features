Java 21 JEP Reference

Java Enhancement Proposals associated with the features demonstrated in this repository.

What is a JEP?

JEP stands for JDK Enhancement Proposal. JEPs describe proposed enhancements and changes to the Java Development Kit.

This page provides a quick reference to the Java 21 JEPs relevant to the features covered by this project.

JEP 430 — String Templates

String Templates provide a template mechanism for combining literal text with embedded expressions. 


String name = "Dinesh";

String message = STR."Hello \{name}";

String Templates were a preview feature in Java 21.

JEP 431 — Sequenced Collections

Sequenced Collections introduce common interfaces for collections that have a defined encounter order.

They provide consistent operations such as first and last element access. 


SequencedCollection<String> values =
        new LinkedList<>();

values.addFirst("Java");
values.addLast("21");

JEP 440 — Record Patterns

Record Patterns allow record components to be directly extracted during pattern matching. 


record Point(int x, int y) {}

Object value = new Point(10, 20);

if (value instanceof Point(int x, int y)) {

    System.out.println(x);
    System.out.println(y);

}

JEP 441 — Pattern Matching for switch

Pattern Matching for switch allows switch expressions and statements to work with type patterns. 


static String describe(Object value) {

    return switch (value) {

        case Integer i ->
                "Integer: " + i;

        case String s ->
                "String: " + s;

        default ->
                "Unknown";

    };

}

JEP 442 — Foreign Function & Memory API

The Foreign Function & Memory API provides mechanisms for Java applications to interact with native code and memory outside the JVM.

In Java 21 this API was delivered as its third preview.

JEP 443 — Unnamed Patterns and Variables

Unnamed patterns and variables allow developers to explicitly indicate that a matched value is not required. 


if (obj instanceof String _) {

    System.out.println("String value");

}

This feature was a preview feature in Java 21.

JEP 444 — Virtual Threads

Virtual Threads are lightweight threads that make it easier to build highly concurrent applications. 


Thread.startVirtualThread(() -> {

    System.out.println(
        "Running on a virtual thread"
    );

});

Virtual Threads became a final feature in Java 21.

JEP 445 — Unnamed Classes and Instance Main Methods

This preview feature simplifies small Java programs by allowing developers to write code without the traditional public static void main structure.

It is intended to make Java easier to learn and suitable for small programs and educational examples.

JEP 446 — Scoped Values

Scoped Values provide a mechanism for sharing immutable data within a bounded execution scope.

They are particularly useful for concurrent applications and work well with virtual threads.

JEP 453 — Structured Concurrency

Structured Concurrency treats groups of related concurrent tasks as a single unit of work.

This makes concurrent task management easier to reason about and handle.

Structured Concurrency was a preview feature in Java 21.

Preview Features

Preview features require explicit compiler and runtime support. 


--enable-preview

For Maven projects, preview support must be configured in the compiler and runtime configuration when the corresponding examples are executed.
