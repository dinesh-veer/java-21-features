Java 21 Feature Overview

Java 21 is a Long-Term Support release containing important improvements to concurrency, pattern matching, collections, string processing and native interoperability.

1. Virtual Threads

Virtual Threads are lightweight threads designed to support large numbers of concurrent tasks with efficient resource usage. 


try (var executor =
         Executors.newVirtualThreadPerTaskExecutor()) {

    executor.submit(() ->
        System.out.println(
            "Hello from a virtual thread!"
        )
    );
}

2. Structured Concurrency

Structured Concurrency provides an approach for treating related concurrent tasks as a single unit of work.

This feature was available as a preview feature in Java 21.

3. Scoped Values

Scoped Values provide a mechanism for sharing immutable data across a bounded scope of execution.

They are particularly useful together with lightweight concurrency mechanisms such as virtual threads.

4. Pattern Matching

Java 21 finalizes pattern matching improvements for switch and record patterns. 


if (obj instanceof Point(int x, int y)) {

    System.out.println(x + y);

}

5. Sequenced Collections

Sequenced Collections provide common operations for accessing elements at the beginning and end of ordered collections. 


SequencedCollection<String> seq =
        new LinkedList<>();

seq.addLast("A");

6. String Templates

String Templates provide a template-based approach for combining strings and embedded expressions. 


String result = STR."Hello \{name}";

String Templates were a preview feature in Java 21.

7. Foreign Function & Memory API

The Foreign Function & Memory API provides Java applications with a mechanism for interacting with native code and memory outside the JVM.

The Java 21 version was the third preview of this API.

8. Unnamed Patterns & Variables

Unnamed patterns and variables allow developers to indicate explicitly that a matched value or variable is intentionally unused.

This feature was available as a preview feature in Java 21.
