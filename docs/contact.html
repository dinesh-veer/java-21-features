Create a Feature Branch 


git checkout -b feature/my-java21-example

Test Your Changes

Before creating a pull request, make sure the project builds successfully. 


mvn clean compile

mvn test

If your example uses a Java 21 preview feature, make sure preview support is enabled as required.

Commit Your Changes 


git add .

git commit -m "Add Java 21 example"

Push Your Branch 


git push origin feature/my-java21-example

Pull Request

After pushing your branch, create a Pull Request against the project's main branch.

Create / View Pull Requests

Contribution Guidelines

  • Keep examples simple and focused.
  • Use Java 21 syntax and APIs appropriately.
  • Include comments where they improve understanding.
  • Keep documentation synchronized with examples.
  • Test changes before submitting a pull request.
  • Clearly describe the purpose of your change.
