Java 21 Examples

Practical examples demonstrating modern Java 21 language, concurrency and API features.

About the Examples

The repository contains small, focused examples intended to demonstrate Java 21 features in isolation. Each example can be studied independently to understand the syntax and behaviour of the corresponding feature.

The examples are designed primarily for learning, experimentation and reference.

Virtual Threads Example

Virtual threads can be created directly using the Java 21 threading API. 


public class VirtualThreadExample {

    public static void main(String[] args) {

        Thread thread = Thread.startVirtualThread(() -> {

            System.out.println(
                "Running on virtual thread: "
                + Thread.currentThread()
            );

        });

        try {

            thread.join();

        } catch (InterruptedException e) {

            Thread.currentThread().interrupt();

        }

    }

}

Virtual Thread Executor Example

An executor can create a new virtual thread for every submitted task. 


try (var executor =
         Executors.newVirtualThreadPerTaskExecutor()) {

    for (int i = 0; i < 10; i++) {

        executor.submit(() -> {

            System.out.println(
                Thread.currentThread()
            );

        });

    }

}

Record Pattern Example 


record Customer(
    String name,
    String email
) {}

Object value =
    new Customer(
        "Dinesh",
        "dveer123@hotmail.com"
    );

if (value instanceof Customer(
        String name,
        String email
)) {

    System.out.println(name);
    System.out.println(email);

}

Record patterns allow record components to be extracted directly during pattern matching.

Pattern Matching for switch 


static String describe(Object value) {

    return switch (value) {

        case Integer number ->
            "Integer: " + number;

        case String text ->
            "String: " + text;

        default ->
            "Unknown value";

    };

}

Sequenced Collections Example 


SequencedCollection<String> values =
        new ArrayList<>();

values.add("Java");
values.add("21");

System.out.println(
    values.getFirst()
);

System.out.println(
    values.getLast()
);

Sequenced Collections provide a consistent API for working with the beginning and end of ordered collections.

String Templates Example 


String name = "Dinesh";

String message =
        STR."Hello \{name}!";

System.out.println(message);

String Templates were a preview feature in Java 21.

Scoped Values Example 


static final ScopedValue<String> USER =
        ScopedValue.newInstance();

ScopedValue.where(
        USER,
        "Dinesh"
).run(() -> {

    System.out.println(
        USER.get()
    );

});

Scoped Values allow immutable contextual data to be made available within a bounded scope.

Structured Concurrency

Structured Concurrency allows multiple related tasks to be started and managed together. 


try (var scope =
         new StructuredTaskScope.ShutdownOnFailure()) {

    var task1 = scope.fork(() ->
        getCustomer()
    );

    var task2 = scope.fork(() ->
        getOrders()
    );

    scope.join()
         .throwIfFailed();

    var customer = task1.get();
    var orders = task2.get();

}

Structured Concurrency was a preview feature in Java 21.

Preview Features

Several Java 21 examples use preview APIs or language features.

Compile preview features using: 


javac --enable-preview --release 21 Example.java

Run them using: 


java --enable-preview Example

Maven Configuration

For Maven projects using preview features, configure the compiler with the Java 21 release and preview flag. 


<properties>

    <maven.compiler.release>21</maven.compiler.release>

</properties>

<build>

    <plugins>

        <plugin>

            <groupId>
                org.apache.maven.plugins
            </groupId>

            <artifactId>
                maven-compiler-plugin
            </artifactId>

            <configuration>

                <compilerArgs>

                    <arg>
                        --enable-preview
                    </arg>

                </compilerArgs>

            </configuration>

        </plugin>

    </plugins>

</build>
