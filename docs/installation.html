Installation & Setup

Set up Java 21 and run the examples from the repository.

Prerequisites

The Java 21 Features project requires:

  • JDK 21
  • Maven
  • Git
  • An IDE such as IntelliJ IDEA, Eclipse or VS Code

1. Install JDK 21

Install a Java Development Kit that supports Java 21.

After installation, verify the Java version: 


java -version

You should see Java 21 in the version information.

2. Verify JAVA_HOME

Make sure JAVA_HOME points to your JDK 21 installation.

macOS / Linux 


echo $JAVA_HOME

Windows 


echo %JAVA_HOME%

3. Install Maven

Verify that Maven is available: 


mvn -version

Verify that Maven is using JDK 21.

4. Clone the Repository

Clone the Java 21 Features repository: 


git clone https://github.com/dinesh-veer/java-21-features.git

Move into the project directory: 


cd java-21-features

5. Import the Project

Open the project in your preferred IDE.

IntelliJ IDEA

  1. Open IntelliJ IDEA.
  2. Select Open.
  3. Select the java-21-features directory.
  4. Allow IntelliJ IDEA to import the Maven project.
  5. Configure the project SDK as JDK 21.

VS Code

  1. Open VS Code.
  2. Open the java-21-features directory.
  3. Install the Java Extension Pack if required.
  4. Configure JDK 21.

6. Compile the Project

Run: 


mvn clean compile

This cleans the previous build output and compiles the project.

7. Run Tests 


mvn test

8. Preview Features

Some Java 21 examples use preview features. These features require the preview flag. 


--enable-preview

When compiling a standalone Java source file: 


javac --enable-preview --release 21 Example.java

Run the compiled class with: 


java --enable-preview Example

9. Maven Preview Configuration

If the project contains preview-feature examples, configure the Maven compiler accordingly. 


<properties>

    <maven.compiler.release>21</maven.compiler.release>

</properties>

<build>

    <plugins>

        <plugin>

            <groupId>
                org.apache.maven.plugins
            </groupId>

            <artifactId>
                maven-compiler-plugin
            </artifactId>

            <configuration>

                <compilerArgs>

                    <arg>
                        --enable-preview
                    </arg>

                </compilerArgs>

            </configuration>

        </plugin>

    </plugins>

</build>

10. Clean Build

If you experience compilation problems, perform a clean Maven build: 


mvn clean
mvn compile

You can also force Maven to update dependencies: 


mvn clean install -U

11. Verify the Environment

Component Command Expected
Java java -version Java 21
Compiler javac -version javac 21
Maven mvn -version Maven available
Git git --version Git available

12. Common Problems

Wrong Java Version

If the project is compiled with an older JDK, Java 21 features may not compile. 


java -version
javac -version

Preview Feature Compilation Error

If a preview feature is used without enabling preview support, compilation can fail.

Add: 


--enable-preview

JAVA_HOME Points to Another JDK

Check JAVA_HOME and make sure it points to JDK 21.

Maven Uses the Wrong JDK

Check Maven's Java version: 


mvn -version
