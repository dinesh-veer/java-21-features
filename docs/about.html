About This Project

Java 21 Features

This repository is a collection of examples demonstrating features introduced or finalized in Java 21.

The goal is to provide small, easy-to-understand examples that developers can use to learn, experiment with and understand modern Java.

Project Goals

Learn

Understand important Java 21 language, API and concurrency features.

Experiment

Run small examples and experiment with the new APIs and language features.

Reference

Use the repository as a quick reference when working with Java 21.

Practice

Build practical knowledge through runnable source-code examples.

Topics Covered

  • Virtual Threads
  • Structured Concurrency
  • Scoped Values
  • Record Patterns
  • Pattern Matching for switch
  • Sequenced Collections
  • String Templates
  • Foreign Function & Memory API
  • Unnamed Patterns and Variables

Java 21 and Long-Term Support

Java 21 is a Long-Term Support release of the Java platform.

LTS releases are commonly used by organizations that prefer a stable Java version with long-term support.

This makes Java 21 an important version for developers who want to adopt modern Java features in production applications.

Important Note About Preview Features

Some Java 21 features were preview features and therefore may require the --enable-preview compiler and runtime option. 


javac --enable-preview --release 21 Example.java

java --enable-preview Example

Check the individual example before running it to determine whether preview support is required.
